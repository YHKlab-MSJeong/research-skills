# 설치·검증 기록

확인일: 2026-10-18. 실제 연구 자료가 아닌 합성 자료로 검증했다. 이 기록은 이후 환경에서도 자동으로 성공한다는 보장이 아니다.

## 도입한 구성

- `research-presentation`: 한국어 공통 지침, 학회·세미나/랩미팅/학위심사 분기, 근거와 한계, 별도 제작 도구 연동.
- `slides`: OpenAI skills 커밋 `e6afb0d74cc75d220df2faf3dd6c635c2dc6a108`의 `skills/.curated/slides` 원본. Apache-2.0 `LICENSE.txt` 포함, 전체 20개 파일을 수정 없이 도입했다.
- 원본의 Python 구문과 JavaScript helper 구문·import를 검사하고, 네트워크·삭제·서브프로세스·파일 출력·symlink 경로를 검토했다. 제작 스크립트는 로컬 변환 도구를 호출하며 출력 경로를 지정해야 한다. 입력 근처 출력과 넘침 검사 종료 코드의 한계는 제작 지침에 반영했다.

## 검증 환경과 재생성

시스템 Node 16은 새 의존성 요구 버전보다 낮아 작업 전용 npm 환경의 Node `22.23.3`으로 검증했다. 전역 설치·셸 설정 변경은 하지 않았다.

| 패키지 | 검증 버전 |
|---|---|
| pptxgenjs | 4.0.1 |
| skia-canvas | 4.0.0 |
| linebreak | 1.1.0 |
| fontkit | 2.0.4 |
| prismjs | 1.30.0 |
| mathjax-full | 3.2.2 |
| python-pptx | 1.0.2 |
| pdf2image | 1.17.0 |

Python 3.11.5의 작업 전용 venv를 사용했다. numpy·Matplotlib·Pillow 등은 기존 환경의 패키지를 읽었으며, 누락된 패키지만 venv에 설치했다. LibreOffice, Poppler, Inkscape 1.2와 `Noto Sans CJK KR`을 사용했다. Matplotlib에는 fontconfig의 글꼴 경로를 명시적으로 등록해 한글 누락을 해결했다.

합성 검증 산출물과 실제 버전을 고정한 `package.json`·`package-lock.json`, Python 패키지 기록, 생성 소스·자산·검사 로그는 `/home/minsu/output/research-presentation-skill-validation-20261018`에 있다. `node_modules`와 venv 자체는 설치 스킬에 포함하지 않는다. 새 작업에서는 해당 작업 공간의 의존성을 확인·준비한다.

예제 디렉터리에서 재생성하려면 작업 전용 환경에 패키지를 복원하고 `make_plot.py`, `deck.js` 순서로 실행한다. `deck.js`는 같은 폴더의 `pptxgenjs_helpers`를 사용하며 수식 rasterization에 Inkscape가 필요하다. Node 설치 패키지까지 복원한 경우 `node_modules/.bin/node`로 실행한다. Python 요구 버전과 전체 패키지 목록은 동봉한 환경 기록을 참고한다.

## 남은 한계

- 샌드박스에서는 LibreOffice·Inkscape의 일부 실행이 차단되어, 작업 전용 설정·출력 경로를 지정한 확대 권한 실행으로 변환을 검증했다. 이후에도 권한이 필요하면 실제 승인 범위에서 처리한다. 글꼴 검사만으로 변환 성공을 추정하지 않고 PDF·PNG 생성도 확인한다.
- 이 환경의 LibreOffice는 MathJax SVG 직접 배치를 정상 표시하지 못했다. 예제는 SVG 원본을 보존하고 표준 rasterizer의 PNG를 배치했다. 수식은 이미지이고 텍스트는 편집 가능하다.
- 실제 Microsoft PowerPoint 실행, 발표장 투사, 다른 운영체제의 글꼴·노트 호환성, 실제 발표 리허설은 수행하지 않았다.
- 일반 `.pptx` 제작 경로를 검증했으며 기존 복잡한 템플릿·매크로·애니메이션·동영상의 보존을 검증한 것은 아니다.
