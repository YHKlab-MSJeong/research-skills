# 패턴과 근거

## 읽는 방법

공통 항목 → 해당 언어 절 → 필요한 경우 출처·한계를 읽는다. 각 패턴은 삭제 명령이 아닌 검토 기준이다. 아래 전후 예시는 이 스킬을 위해 만든 예문이며 연구 논문의 인용이나 실험 결과가 아니다. 후문은 전문·주변 문맥과 수정 강도가 허용할 때만 적용한다.

근거 표시는 **W: 편집자 관찰**, **P: 영어 문체 비교 연구**, **V: 영어 논문 초록의 어휘 변화 연구**, **E: 이 스킬의 편집 제안**으로 구분한다. 한국어 예시는 영어 연구로 검증된 한국어 판별 지표가 아니다.

## 공통 패턴

| 징후·근거 | 고칠 때 / 유지할 때 | 전 → 후 예시 |
|---|---|---|
| 중요성·홍보 수식 W | 근거 없으면 줄임 / 입증된 평가·요청된 광고는 유지 | ‘획기적인 기능으로 파일을 저장합니다.’ → ‘파일을 저장합니다.’ |
| 사실 뒤 의미 부여 W | 근거 없는 해석은 덜어냄 / 논증된 해석은 유지 | ‘좌석은 20개로, 공동체의 활력을 상징합니다.’ → ‘좌석은 20개입니다.’ |
| 모호한 권위 W | 출처 확인 필요 표시 / 확인된 귀속은 유지 | ‘전문가들은 효과가 있다고 말합니다.’ → 본문 유지 + ‘전문가·근거 확인 필요’ 별도 표시 |
| 반복 대조 W | 불필요한 오해 교정은 단순화 / 실질적 구별은 유지 | ‘단순한 알림이 아닙니다. 일정 알림입니다.’ → ‘일정 알림입니다.’ |
| 삼단 나열 W | 중복 형용사는 축소 / 서로 다른 세 항목은 유지 | ‘간단하고 쉽고 복잡하지 않은 설정’ → ‘간단한 설정’ |
| 정형적 전망 W | 근거 없는 낙관은 삭제 / 실제 계획·한계는 유지 | ‘수정안은 월요일 제출합니다. 미래는 밝습니다.’ → ‘수정안은 월요일 제출합니다.’ |
| 과도한 서식 W | 불필요한 장식은 정리 / 요청 형식은 유지 | ‘✅ **제출일:** 금요일’ → ‘제출일은 금요일입니다.’ |
| 챗봇 잔여 문구 W | 납품 본문에서 제거 / 대화 맥락·직접 인용은 유지 | ‘물론입니다! 아래는 공지입니다. 내일 휴무입니다.’ → ‘내일 휴무입니다.’ |
| 같은 주장 재진술 E | 새 정보 없는 반복은 합침 / 조건·강조가 필요하면 유지 | ‘예약해야 합니다. 즉, 사전 예약이 필요합니다.’ → ‘사전 예약이 필요합니다.’ |
| 균일한 문장·문단 E | 호흡이 독해를 방해하면 조절 / 병렬 설명은 유지 | ‘오늘 점검합니다. 오늘 백업합니다.’ → ‘오늘 점검하고 백업합니다.’ |

확인되지 않은 근거를 매끈한 단정으로 바꾸지 않는다. 서식 정리는 본문의 강조·인용·링크 의미를 바꾸지 않는 범위에서 수행한다. 목록이나 대조 구조가 있다는 이유만으로 바꾸지 않는다.

## 한국어 적용

아래 항목은 **E: 한국어용 편집 제안**이다. 번역투처럼 느껴지는 표현도 글의 장르와 앞뒤 문맥에 따라 자연스러울 수 있다.

| 징후 | 고칠 때 / 유지할 때 | 전 → 후 예시 |
|---|---|---|
| 명사화·빈 동사 | 행위가 흐려지면 동사로 / 개념명·법률용어는 유지 | ‘측정의 수행을 진행했습니다.’ → ‘측정했습니다.’ |
| 번역투 연결 | 불필요하게 늘어지면 단순화 / 독립된 의미가 있으면 유지 | ‘설정을 바꾸는 것이 가능합니다.’ → ‘설정을 바꿀 수 있습니다.’ |
| 접속 표현 반복 | 논리 관계가 이미 분명하면 축소 / 대조·원인 연결은 유지 | ‘또한 표를 넣었습니다. 또한 그림도 넣었습니다.’ → ‘표와 그림을 넣었습니다.’ |
| 모호한 주어·행위자 | 주어진 행위자가 있으면 명시 / 행위자를 모르면 만들지 않음 | 앞 문맥에 ‘운영팀’이 명시됨: ‘금요일에 안내가 이루어집니다.’ → ‘운영팀이 금요일에 안내합니다.’ |
| 문단마다 요약 | 반복일 뿐이면 생략 / 절 전환·긴 논증 요약은 유지 | ‘배송은 이틀 걸립니다. 요약하면, 배송 기간은 이틀입니다.’ → ‘배송은 이틀 걸립니다.’ |
| 말투가 획일화됨 | 원문 말투가 사라지면 복원 / 요청한 톤 변경은 적용 | 원문 ‘이건 좀 번거롭더라.’를 ‘이는 다소 비효율적입니다.’로 바꾸지 않음 |

학술문에서는 ‘수렴’, ‘전하 밀도’, ‘상관’ 등 정확한 개념을 쉬운 말로 바꾸다가 의미를 잃지 않도록 한다. 필요한 ‘가능성이 있다’, ‘이 조건에서는’, ‘통계적으로 유의하지 않았다’를 군더더기로 취급하지 않는다.

## English application

P와 V는 영어 자료의 관찰이다. 아래 수정 예시는 **E: 해당 관찰을 참고한 편집 제안**이다. 연구에서 발견한 빈도 차이를 문장별 금지 규칙으로 사용하지 않는다.

| 징후·근거 | 고칠 때 / 유지할 때 | 전 → 후 예시 |
|---|---|---|
| 문체 어휘 밀집 V | 수식이 내용보다 앞서면 축소 / 정확한 기술 용례는 유지 | “We meticulously delve into the results.” → “We examine the results.” |
| 명사화 P | 행위가 흐려지면 동사로 / 학술 개념명은 유지 | “We performed an evaluation of the fit.” → “We evaluated the fit.” |
| 덧붙인 분사절 P | 분명한 추가 정보면 본문에 통합 / 필요한 동시 행동·한계는 유지 | “The tool saves files, allowing users to save files.” → “The tool saves files.” |
| 장르 불일치 P | 대화·공지를 보고서처럼 쓰면 조정 / 학술적 정밀성은 유지 | Casual message: “Your attendance would be appreciated.” → “Hope you can join us.” |
| 단순 관계의 과장 E | 의미 없는 수식만 축소 / 실제 개념 차이는 유지 | “This feature serves as a mechanism for file storage.” → “This feature stores files.” |
| 용어 동의어 돌려쓰기 E | 동일 개념의 이름이 흔들리면 통일 / 실제 다른 개념은 구분 | 같은 논문의 ‘charge density’를 문체 변화만을 위해 ‘electrical concentration’으로 바꾸지 않음 |

수동태를 일괄 능동태로 바꾸지 않는다. P는 모델·구조별 차이를 보고하므로 ‘AI는 항상 수동태를 많이 쓴다’ 같은 규칙을 뒷받침하지 않는다. Em dash나 특정 단어도 필요한 기능이 있으면 유지한다. 문장 길이를 인위적으로 섞거나 논문을 구어체로 바꾸지 않는다.

## 출처와 적용 한계

확인일: 2026-10-18. 링크된 자료 세 개를 바탕으로 위 편집 지침을 작성했다. 원문 목록 전체의 재현이나 새로운 탐지 모델이 아니다.

- **W — [Wikipedia: Signs of AI writing](https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing).** 위키백과 편집 현장의 관찰이며 정책·판별 규칙이 아니다. 위키 전용 문법·등재 관행은 일반 글에 적용하지 않는다. 패턴은 시대와 모델에 따라 달라진다.
- **P — [Do LLMs write like humans? Variation in grammatical and rhetorical styles](https://arxiv.org/abs/2410.16107), [PNAS 출판본](https://doi.org/10.1073/pnas.2422455122), 2025.** 조사한 GPT-4o·Llama 계열의 영어 글에서 문법적 선호와 장르별 문체 재현의 차이를 분석했다. 모든 모델·시점·언어로 일반화할 수 없다.
- **V — [Delving into LLM-assisted writing in biomedical publications through excess vocabulary](https://arxiv.org/abs/2406.07016), [Science Advances 출판본](https://doi.org/10.1126/sciadv.adt3813), 2025.** 2010–2024년 영문 의생명 논문 초록의 집합적 어휘 변화를 분석했다. 개별 글의 AI 사용 여부를 판별하지 못하며 직접 사용과 사람의 어휘 습관 변화를 분리하지 못한다.

표의 한국어 표현, 예문과 편집 방법은 스킬 작성자의 적용 제안이다. 직접 인용·전문용어·실질적인 근거가 있는 표현은 관찰된 패턴과 닮았어도 유지할 수 있다. 스타일 수정은 사실 확인을 대신하지 않는다.
