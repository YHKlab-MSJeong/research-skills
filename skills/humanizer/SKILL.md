# 휴머나이저

글쓴이의 의도와 말투를 살리면서 독자가 구체적인 내용을 쉽게 이해하도록 다듬는다. 특정 표현의 존재보다 그 표현이 문맥에서 하는 일을 판단한다. 자연스러움은 무조건 짧게 쓰거나 구어체로 바꾸는 것을 뜻하지 않는다.

## 적용과 강도 선택

- 원문과 요청에서 언어, 독자, 목적, 장르, 말투, 분량·서식 제약을 파악한다. 수정 강도는 아래 절차로 확인한다. 그 밖의 추가 질문은 결과를 실질적으로 바꾸는 정보가 빠져 있을 때만 한다.
- 기존 글의 수정 강도가 불명확하면 편집 전에 한 번 선택을 요청한다. 선택지는 **부분 수정(추천)**, **문단 재구성**, **전면 재작성**으로 제시하고 차이를 짧게 설명한다. 답을 기다리는 중에는 수정본을 먼저 제시하거나 원문을 덮어쓰지 않는다.
- 사용자가 선택을 맡기거나 선택 질문 도구가 응답 없이 종료된 경우 부분 수정을 적용한다. 비동기 질문을 보낸 직후나 아직 답을 기다리는 상태는 무응답 종료로 간주하지 않는다.
- 부분 수정은 문제가 있는 표현만 고친다. 문단 재구성은 문장 순서와 문단을 바꿀 수 있다. 전면 재작성은 사실과 의도를 유지하면서 표현과 구성 전체를 새로 쓸 수 있다. 모든 강도에 아래 보존 원칙이 적용된다.
- 같은 작업에서 이미 선택한 강도는 유지한다. ‘맞춤법만’, ‘구성은 그대로’, ‘전면 재작성’처럼 범위가 명확하면 다시 묻지 않고 그 범위를 따른다.
- 새 글 작성에는 수정 강도를 묻지 않는다. 제공된 사실과 작성 조건으로 초안을 작성한 뒤 편집 기준을 적용한다. 새 글의 말투는 명시된 독자·장르에 맞춘다.
- 명시적으로 부른 경우 요청 범위 안에서 적용한다. 자동 선택은 자연스러운 문체나 AI 티 개선을 요청한 경우에 한정하며, 모든 글쓰기·번역 요청에 일반화하지 않는다.

## 보존 원칙

- 수치·부호·단위·날짜·고유명사·전문용어·수식·코드·인용문·출처와 그 출처가 뒷받침하는 주장을 보존한다. 전문용어를 반복 회피용 동의어로 바꾸지 않는다.
- 조건·예외·부정·비교 기준·인과와 상관의 차이·주장의 확실성 수준을 유지한다. ‘가능성이 있다’를 단정으로, ‘일부’를 전체로 바꾸지 않는다.
- 편집에서는 입력 언어와 존댓말·반말, 문체를 유지한다. 혼합 언어의 용어를 임의로 번역하지 않는다. 사용자가 요청한 번역·말투 변경은 해당 범위에만 적용한다.
- 경험·감정·관찰·사례·통계·출처를 꾸며 넣지 않는다. 구체성이 부족하면 이미 제공된 세부 사항을 활용한다. 필수 사실이 없으면 질문하고, 없어도 작성 가능한 부가 사실은 생략한다.
- 오탈자·속어·불필요한 감정 표현으로 사람다움을 연출하지 않는다. 필요한 형식, 설명, 논리 연결, 한계를 문체상의 이유로 없애지 않는다.
- 인용문 안의 표현은 다듬지 않는다. 직접 인용의 문체, 정당한 수사법과 기술적으로 필요한 용어는 유지할 수 있다.

## 편집 절차

1. 보존해야 할 사실·조건·인용·말투와 사용자가 허용한 변경 범위를 확인한다.
2. [패턴과 근거](references/patterns.md)의 공통 항목과 해당 언어 절을 참고한다. 첫 사용에는 출처·한계도 확인한다. 혼합 글에는 관련된 두 언어 절을 적용한다.
3. 반복되는 내용, 추상적인 수식, 근거 없는 의미 부여, 형식적인 도입·결론, 장르에 맞지 않는 문장·서식을 검토한다. 실제 이해를 방해하는 부분만 선택한 강도 안에서 고친다. 단어 일괄 치환, 금지어 목록, 고정 문장 길이·문단 수를 쓰지 않는다.
4. 편집 후 원문과 대조한다. 사실·수치·인용 연결·불확실성·말투를 확인하고, 설명이나 조건이 빠졌거나 새 주장이 생겼으면 복원한다. 새 글에서는 제공된 자료와 대조한다.
5. 문단의 흐름과 문장의 리듬을 읽고 확인한다. 고칠 필요가 없으면 원문을 그대로 반환할 수 있다.

## 출력과 확인이 필요한 내용

- 기본 출력은 수정본 또는 새 글 본문만이다. 서문, 자동 요약, 자기평가, 상시 변경 내역을 덧붙이지 않는다. 사용자가 진단·이유·전후 비교를 요청하면 그 형식으로 답한다.
- 의심스러운 사실·수치·인용은 임의로 확정·교정·삭제하지 않는다. 편집 가능한 본문을 제공한 뒤 확인이 필요한 지점을 짧게 구분해서 알린다. 본문의 의미를 정할 수 없는 핵심 모순은 먼저 질문한다.
- 문체 편집만으로 출처를 검증했다고 말하지 않는다. 사실 확인을 요청받았거나 결과에 필수적인 경우 관련 원문을 별도로 확인하고, 확인한 범위를 밝힌다.
- AI 작성 여부를 단정하거나 탐지기 점수·통과를 보장하지 않는다. 출처 자료는 편집 판단의 참고이며 판별 규칙이 아니다. 일반적인 수정본마다 연구 출처나 이 안내를 덧붙일 필요는 없다.
