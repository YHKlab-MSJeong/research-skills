# 연구논문 글쓰기

독자가 연구 질문, 근거, 결론과 적용 한계를 따라가며 평가할 수 있는 원고를 만든다. 제공된 연구의 전달을 개선하되 결과나 논증의 공백을 만들어 채우지 않는다.

## 요청에 맞게 시작하기

- 제공된 원고·메모·그림과 요청에서 작성 단계, 독자, 대상 저널, 언어, 분량, 편집 범위를 파악한다. 결과나 범위를 실질적으로 바꾸는 누락만 질문한다.
- 원고 언어는 요청을 따르고, 지정이 없으면 입력 언어를 유지한다. 설명은 기본적으로 한국어로 한다. 번역에서도 과학적 의미와 주장 강도를 보존한다.
- 한 문장 교정은 직접 처리한다. 개요·절 작성·구조 검토에서는 [상세 가이드](references/writing-guide.md)의 해당 항목을 읽는다. 출처 설명이나 원칙의 근거가 필요하면 [출처와 확인 범위](references/sources.md)를 읽는다. 모든 참조를 매번 읽을 필요는 없다.
- 제공되지 않은 내용은 ‘누락’으로 단정하지 않는다. 발췌문만으로 판단할 수 없는 사항은 확인 범위를 밝힌다.

## 작업 방식

| 요청 | 수행할 일 | 기본 산출물 |
|---|---|---|
| 구상·개요 | 질문·기여·주장과 근거의 연결을 정리하고 논증 순서로 배치 | 핵심 메시지, 개요, 필요한 근거 |
| 초안·절 작성 | 제공된 근거로 작성하고 미확인 사실을 분리 | 초안, 작성에 필요한 누락 정보 |
| 논리 검토 | 주장–근거 대응, 대안 해석, 절·그림 사이의 정합성 검토 | 중요한 문제부터 위치·이유·수정 제안 |
| 문장 교정·번역 | 요청한 범위에서 의미·흐름·표현 개선 | 수정문, 의미 있는 변경 이유 |

문법 교정만 요청하면 절·문단 재배치를 적용하지 않는다. 발견한 논리 문제는 필요한 경우 짧게 별도 제안한다. 전체 개작을 요청하지 않은 원고는 기존 논증과 스타일을 기준으로 최소한으로 수정한다.

## 의미와 근거 보존

- 수치, 단위, 부호, 비교 기준, 조건, 표본 수, 오차·불확실성, 식·기호·첨자, 인용 키와 주장 사이의 연결을 임의로 바꾸지 않는다. 충돌이나 오류 의심은 확인 항목으로 제시한다.
- 관찰·계산 결과, 해석, 가설을 구별한다. 문장을 유창하게 만들면서 인과성·기전·신규성·일반성·확신의 강도를 높이거나 낮추지 않는다. 강도 조정이 필요하면 근거와 변경을 명시한다.
- 없는 결과, 참고문헌, DOI, 방법 조건, 통계적 유의성, 재현·수렴 완료를 만들지 않는다. 필요한 자리는 `[확인 필요: …]`로 표시한다. 근거가 부족한 기여는 잠정적으로 표현하고 확인할 증거를 적는다.
- 데이터에 맞춰 논증을 구성한다. 핵심 메시지를 위해 불일치, 음성 결과, 한계 또는 타당한 대안 해석을 숨기지 않는다.
- 수치 시뮬레이션의 수렴, 모델의 타당성, 실험과의 일치는 각각 별도 근거가 필요하다. 글 편집 자체는 분석·계산의 완료나 검증을 뜻하지 않는다.
- 원고 검토를 이유로 원본 연구 데이터·계산 출력을 수정하거나 계산을 실행하지 않는다. 파일 편집 요청이 있으면 지정된 원고 범위에만 적용한다.

## 논리와 표현

핵심 기여를 드러내고 결과를 이해에 필요한 순서로 연결한다. 하나의 기여가 여러 측면을 가질 수 있으므로 기여 수를 억지로 줄이지 않는다. 각 문단의 역할과 앞뒤 연결을 점검하고, 같은 개념에는 일관된 용어를 쓴다.

독자의 기존 지식에서 새 정보로 이어지는 배치와 강조 위치를 활용하되, 일정한 문장 길이·능동태·문단 공식·절 구성을 강제하지 않는다. 결과와 논의의 통합 등 분야·논문 형식과 사용자가 지정한 구성을 존중한다. 특정 저널의 규칙을 말할 때는 해당 규칙을 확인한다.

## 검색과 출처

일반 교정·번역은 제공된 내용으로 처리한다. 새 문헌·사실·신규성·저널 규정을 확인해야 할 때만 필요한 검색을 한다. 그때는 `research-with-sources`가 있으면 함께 활용하고, 없으면 원논문·공식 안내를 직접 확인한다. 검색하지 않은 문헌을 검증했다고 말하지 않는다.

일곱 글쓰기 자료는 이 스킬의 근거이며 연구논문 속 과학적 주장을 입증하는 인용이 아니다. 원고에 자동으로 추가하지 않는다. 접근하지 못한 책의 장이나 강의 내용을 확인한 것처럼 설명하지 않는다.

## 마무리

수정 후 사실·수치·기호·인용·조건·주장 강도를 원문과 대조한다. 전체 원고를 다룰 때는 제목·초록·본문·그림의 일관성도 확인한다. 수정문을 먼저 제시하고, 중요한 변경 이유와 해결되지 않은 사항만 요청 규모에 맞게 덧붙인다. 교정문만 요청하면 그 형식을 따른다.
