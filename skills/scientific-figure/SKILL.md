# 연구 Figure 제작

독자가 데이터와 비교 조건을 읽고 연구 주장을 평가할 수 있는 그림을 만든다.
목적에 맞는 시각적 구조와 정확한 표현을 우선하며, 탐색 단계에서는 결론을 미리 정하지 않는다.

## 요청에 맞게 시작하기

- 신규 제작·설계 제안·기존 그림 수정·검토 중 요청한 작업을 수행한다. 검토만 요청하면 파일을 수정하지 않는다.
- 목적, 독자, 입력 자료, 비교 대상, 대상 저널, 출력 위치를 확인한다. 결과·범위·계산 비용을 실질적으로 바꾸는 모호성만 질문한다. 나머지는 합리적인 가정을 밝히고 진행한다.
- 우선순위는 사용자 지정, 해당 저널·그림 유형의 확인된 규격, 기존 그림의 유지 범위, 이 스킬의 신규 그림 기본값 순서로 정한다. 규격과 요청이 충돌하면 차이를 알리고 요청을 따른다. 충돌이 남은 결과를 제출 규격 준수로 표현하지 않는다.
- 신규 그림은 Nature 본지의 main figure를 기본 프로필로 삼는다. 기존 그림의 좁은 수정에서는 요청한 속성만 바꾸고 전체 Nature 양식을 다시 적용하지 않는다.
- 설계·검토에는 [설계 가이드](references/design-guide.md)의 해당 항목을, 신규 제작·Nature 양식에는 [Nature 프로필](references/nature-profile.md)을 읽는다. 근거 확인이나 규격 갱신에는 [출처](references/sources.md)를 읽는다.

## 제작과 수정

1. **질문과 증거:** 그림이 답할 질문과 필요한 비교를 짧게 정리한다. 불일치·음성 결과·불확실성을 메시지에 맞춰 숨기지 않는다.
2. **데이터 확인:** 입력 경로, 물리량·단위·부호·기준값·표본 단위와 기존 변환을 확인한다. 제시된 근거 이상의 기전·인과성·수렴을 주장하지 않는다.
3. **시각적 설계:** 비교 과제에 맞는 그래프와 패널 연결을 선택한다. 축·색상 범위·범례·패널 표시는 실제 게재 크기에서 읽히게 한다.
4. **구현:** 기존 plotting 코드와 환경을 우선한다. 새 Matplotlib 작업은 [독립 템플릿](assets/nature_template.py)을 복사·수정해 시작할 수 있다. 예제의 합성 데이터는 실제 연구 결과로 사용하지 않는다. 모식도는 SVG·Matplotlib patches 등 편집 가능한 벡터 요소로 만든다.
5. **검증:** 수치·범위·단위·레이블을 입력과 대조하고 그림을 직접 본다. 축소된 최종 크기에서 겹침·잘림·범례·색상 구별을 확인한다. PDF 글꼴·텍스트와 최종 크기도 가능한 도구로 점검한다.

## 데이터와 변경 범위 보존

- 원본 데이터·계산 출력은 읽기 전용으로 사용하고 파생 그림·코드·표는 별도 출력 위치에 둔다. plotting 요청으로 SCF, 데이터 재획득, 제출·재제출·취소를 수행하지 않는다.
- 정규화, smoothing, interpolation, baseline·에너지 기준 이동, 데이터 제외는 의미를 바꿀 수 있다. 기존 정의를 보존하고, 새 변환이 필요하면 목적과 방법을 밝히며 중요한 선택은 확인한다.
- 스타일만 수정할 때는 입력 해시나 수치 배열, 기존 설정과 변경 범위를 대조한다. 불필요하게 데이터 추출·대각화·계산을 반복하지 않는다. 기존 생성 그림의 교체는 사용자 요청에 포함된 범위에서 수행한다.
- 테스트는 합성 데이터 또는 독립 복사본·별도 출력으로 수행한다. symlink·절대 출력 경로·캐시·하위 프로세스가 원본에 도달할 수 있으면 중지하고 예상 영향과 격리 선택지를 제시한다.
- 단일 결정론적 계산, k-point, SCF iteration, parameter-grid point를 독립 반복 표본으로 간주해 오차막대나 p-value를 만들지 않는다. 통계적 분석이 필요한 반복·표본 데이터에는 실제 설계에 맞는 방법을 사용한다.
- 측정 이미지의 부분 삭제·선택적 보정·생성형 채움으로 데이터를 바꾸지 않는다. Nature용 figure asset에는 생성형 래스터 이미지 도구를 사용하지 않고 실제 데이터와 검증 가능한 벡터 구성을 사용한다. 코드 작성 보조와 생성형 이미지 생성을 구분한다.

## 완료 보고

그림과 재현 가능한 코드·실행 방법을 제공하고, 적용한 양식·실제 글꼴·데이터 변환·검증·남은 제한을 요청 규모에 맞게 설명한다. 파일 출력이 없던 검토·설계 요청에는 해당 제안만 제공한다. 통계·조건이 불명확하면 캡션 초안에 확인 필요로 표시한다. 캡션 본격 집필은 설치된 `scientific-paper-writing`의 범위를 참고한다.

PDF는 편집 가능한 제출 후보, PNG는 확인용 미리보기로 구분한다. 실제 저널과 그림 유형의 최신 규정을 확인하지 않은 결과를 제출 요건 충족으로 보증하지 않는다. 그림 생성·정적 검사 통과를 원 계산의 완료나 물리적 수렴으로 표현하지 않는다.
