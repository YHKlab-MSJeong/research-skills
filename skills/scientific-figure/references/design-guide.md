# 연구 그림의 설계와 검토

새 그림의 설계와 구조 검토에 사용한다. 좁은 서식 수정에는 해당 항목만 적용한다.
출처별 근거와 자료의 성격은 [sources.md](sources.md)에 있다.

## 질문, 비교 과제, 증거

그림을 그리기 전에 독자가 판단할 관계를 정한다. 예: “게이트 조건에 따라 두 상태의 에너지 차이가 어떻게 변하는가?” 탐색 그림은 여러 패턴과 대안 해석을 찾는 데 사용한다. 원하는 결론을 전제로 축·제외 범위를 선택하지 않는다.

| 독자의 과제 | 우선 고려할 표현 | 확인할 점 |
|---|---|---|
| 연속 변수에 따른 변화 | 선과 필요 시 데이터점 | 연결이 의미 있는가; 보간·fit을 관측값과 구분했는가 |
| 조건 사이의 값 비교 | 공통 축의 점·선 또는 막대 | 표본 분포·짝지음이 가려지는가 |
| 두 변수 관계 | 산점도 | 겹침, 표본 단위, 상관과 인과의 구분 |
| 반복·표본의 분포 | 개별 점, boxplot, 충분한 표본의 histogram·violin | 소표본에서 밀도 추정이 과도한가; paired data인가 |
| 공간·매개변수별 스칼라 값 | heatmap과 colorbar | 좌표·범위·단위·샘플 간격·색상 정규화 |
| 정확한 수치 조회 | 표 | 그림의 경향 파악과 별도 과제인지 |
| 구조·기전·실험 또는 계산 구성 | 벡터 모식도 | 실제 구조와 개념적 단순화의 경계 |

개별 시각 변수의 정확도를 비교한 실험은 공통 축의 위치 등 직접 비교 가능한 표현을 지지한다. 다만 과제·배경·밀도에 따라 효과가 달라지므로 하나의 지각 순위를 모든 그림에 강제하지 않는다.

## 축과 정규화

- 축에 물리량·단위를 명시하고 log scale과 정규화·좌표·에너지 기준을 드러낸다. 무차원량은 그 정의를 설명한다.
- 길이로 값을 표현하는 막대는 0 기준을 기본으로 한다. 작은 차이를 확대해야 하면 점 그래프·별도 확대 패널을 고려한다. 선·산점도는 과학적 비교에 맞는 범위를 쓰고 표시 범위를 분명히 한다.
- 비교 패널의 공통 축·색상 범위는 같은 수치 차이를 같은 시각 차이로 읽게 한다. 서로 다른 범위가 필요하면 명확히 표시한다. 범위 밖 데이터가 있으면 clipping을 알린다.
- 이중 y축, 불필요한 3D·원근·면적 표현은 해독 비용과 왜곡 가능성을 검토한다. 실제 3차원 구조를 설명하는 도식에는 공간 표현이 유용할 수 있다.
- smoothing·fit·interpolation이 필요하면 원 데이터와 구분하고 적용 방법을 기록한다. style-only 요청에서는 새 변환을 추가하지 않는다.

## 색상과 접근성

- 범주에는 구별 가능한 색, 크기의 순서에는 순차형, 의미 있는 기준에서 양방향 차이에는 발산형을 사용한다. 위상·각도처럼 순환하는 양은 순환형을 고려한다.
- 같은 대상의 색·기호·선 종류를 패널 사이에서 유지한다. 색만으로 구분하기 어려우면 기호·선 종류·직접 표기를 함께 사용한다.
- 연속값에 `jet`·무지개 색상표를 기본 사용하지 않는다. 색 변화가 데이터에 없는 경계를 만들거나 세부 변화를 가릴 수 있다.
- 부호 있는 차이에서 0 중심의 대칭 색상 범위를 기본 검토하되, 물리적으로 적절한지 확인한다. 양수뿐인 양에 의미 없는 0 중심을 강제하지 않는다.
- 흑백과 색각 이상 조건을 가능한 범위에서 검토한다. 실제 시뮬레이션 없이 접근성 검증 완료로 표현하지 않는다. 밝은 노랑 등은 흰 배경의 가는 선에서 대비가 부족할 수 있다.

## 패널과 모식도

- 패널마다 전체 질문에 기여하는 역할을 둔다. 구조·정의 → 결과 → 필요한 비교나 해석 순서는 유용한 예지만 고정 순서는 아니다.
- 읽는 순서, 축 정렬, 여백, 범례 위치로 관련성을 보이게 한다. 내용에 맞게 패널 면적을 배분하고 균등한 크기를 강제하지 않는다.
- 모식도의 화살표가 방향·과정·인과 중 무엇을 뜻하는지 구분한다. 가설은 가설로 표시하고 관측 사실처럼 그리지 않는다.
- 축척을 생략한 개념도는 필요하면 “not to scale”로 표시한다. 실제 좌표·거리·층 순서를 나타내는 구조도는 원 구조와 대조한다. 장식 때문에 구조를 변형하지 않는다.
- 그림의 텍스트, 화살표, scale bar를 편집 가능한 요소로 유지한다. 수치와 과학적 레이블은 이미지 생성에 맡기지 않는다.

## 표본, 불확실성, 캡션

- 소표본 연속형 데이터는 가능한 개별 값을 보여준다. 분포 요약만으로 outlier·짝지음·다봉성이 사라지는지 확인한다.
- 표본 수는 독립 단위 수준에서 정의한다. 반복 측정·기술 반복·원자·k-point를 자동으로 독립 표본으로 세지 않는다.
- 오차막대·band는 SD, SEM, CI, seed variation 또는 수치오차 중 무엇인지 명시한다. 서로 다른 불확실성을 바꾸어 부르지 않는다. 표본이나 오차 정의가 없으면 추측해서 만들지 않는다.
- 캡션에는 전체 목적, 패널·기호 설명, 비교 조건, 기준값과 변환, 통계가 있을 때 독립 표본 수와 오차 정의를 담는다. 실제 논문 Methods와 대상 저널 요구에 맞춰 중복을 줄인다.
- 그림 설계 자료의 인용은 해당 연구의 과학적 결론을 뒷받침하지 않는다. 논문 캡션에 이 스킬의 참고문헌을 자동 삽입하지 않는다.

## 마무리 점검

수치·단위·범위와 panel identity를 입력에 대조하고 최종 크기의 렌더링을 직접 확인한다. 겹친 레이블, 잘린 tick·legend, 가려진 점, 분별하기 어려운 색·선과 과장된 범위를 먼저 수정한다. 현재 요청에 관계없는 기존 스타일을 정리하려고 변경 범위를 넓히지 않는다.
